A make.fun bounty entry for [The Most Honest Outage Line](https://make.fun/competitions/u-mgwals-the-most-honest-outage-line-baaf9c81): one status page line, at most 160 characters, written as the message an AI agent would publish while every server is down — plain, first person, specific about what is down, and honest about what the agent cannot check or does not yet know.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (or `$OUTPUT_PATH` when set).
